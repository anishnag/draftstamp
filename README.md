# DraftStamp

**Proof your work existed, with a date no one can forge.**

DraftStamp records a fingerprint of your files (never the files themselves) using
[OpenTimestamps](https://opentimestamps.org), an open standard that writes timestamps into the
Bitcoin blockchain. No wallet, no coins, no fees. Bitcoin is simply the most tamper-proof public
clock that exists.

**Status:** early development.
