How it works

A timestamp for every draft, kept with the draft.

DraftStamp builds on OpenTimestamps, the open standard for timestamping in Bitcoin, and adds what ongoing work needs.

Your files→Salted Merkle tree→One 32-byte commitment→OpenTimestamps calendars→Bitcoin block
01

Stamp

Point it at a folder or a file. Every file's contents and path are committed, with a random salt each, into one value sent to the free public calendars.

02

Keep

The exact files, a receipt and the proof stay together in a local vault. When Bitcoin confirms, usually within hours, upgrade completes the proof.

03

Share

Share any file, folder or selection, each file with its own standard .ots. The salts keep everything you didn't share hidden.

Verification

Anyone can check it. Without us.

Every shared file comes with an ordinary OpenTimestamps proof. Whoever receives it uses the official client, or any other implementation.

  • Standard proofsChecked with ots verify -f, like any OpenTimestamps proof.
  • Private by designThe calendars see one random-looking value. A shared file reveals only itself.
  • Built to lastA confirmed proof needs only Bitcoin's block headers. No company has to survive.
  • Open formatsFully specified, with test vectors from an independent implementation.

FAQ

Questions

Do I need Bitcoin or a wallet?

No. The OpenTimestamps calendars are free public services that batch everyone's timestamps into Bitcoin transactions they pay for.

What exactly does a stamp prove?

That these exact bytes existed by the time of a Bitcoin block, give or take a couple of hours. It shows possession at a time, not authorship.

How is this different from running ots stamp?

DraftStamp's proofs work with the official client. It adds the workflow around them: whole folders as one record with each file's path bound in, the exact files kept with each proof, project history, and private sharing of any file or folder.

What if I lose my vault?

You lose the proofs you hadn't shared or exported, since a proof is only useful next to the exact files. Keep ~/.dsvault in your backups.
